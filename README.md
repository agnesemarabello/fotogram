# 📸 Fotogram – Social Network Universitario per la Condivisione di Immagini
Fotogram è un progetto sviluppato nell'ambito del corso Basi di Dati e Web (A.A. 2024/2025), incentrato sulla realizzazione di un social network minimale focalizzato sulla condivisione di immagini tra utenti. Il sistema implementa un'architettura completa back-end con PostgreSQL e Node.js (Express), fornendo API REST per funzionalità tipiche dei social: pubblicazione di post, gestione delle sessioni utente, interazioni sociali (like/follow), segnalazioni, e moderazione.
Tra le caratteristiche principali:

- Registrazione, login/logout e gestione delle sessioni JWT.

- Pubblicazione di post con immagini e testo.

- Sistema di like e follow tra utenti.

- Segnalazione e moderazione dei contenuti inappropriati.

- Ruoli differenziati: utente, moderatore, admin.

- Ottimizzazione per il caricamento e caching delle immagini profilo.

- API REST documentate e sicure, con validazione token e gestione dei ruoli.

Il progetto include un database relazionale progettato con schema ER e relazionale ottimizzati, insieme all’implementazione delle relative API per supportare tutte le operazioni previste dal social.
